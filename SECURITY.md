# Security policy

[한국어](SECURITY.ko.md)

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/M1n9yu23/gil-englishapp/security/advisories/new), not in a public issue.
Include the app version, the device and Android version, and the steps that reproduce it.

## Scope

Gil has no server or account and does not request the internet permission, so everything it stores stays on the phone.
A report is in scope when another app, a link or a file can read or change that data, or make the app do something the learner did not ask for.
The `gil://` links and the backup files the app imports are examples.

Problems that need a rooted device are out of scope.

## Supported versions

Only the latest release gets fixes.
